# 🚀 Getting Started

```bash
git clone https://github.com/omniaosamamahmood-prog/Finova.git

cd Finova
```

### Frontend

```bash
cd client

npm install

npm run dev
```

### Backend

```bash
cd server

npm install

npm run dev
```

---

# 🔑 Environment Variables

### Client

```env
VITE_API_URL=
VITE_GOOGLE_CLIENT_ID=
```

### Server

```env
DATABASE_URL=
DIRECT_URL=
JWT_SECRET=
GOOGLE_CLIENT_ID=
EMAIL_USER=
EMAIL_PASS=
APP_URL=
```
